# 🍽️ CampusBite – Restaurant Ordering & Delivery Platform

CampusBite is a full-stack restaurant ordering and delivery platform that allows customers to explore restaurants, browse menus, place orders, and track deliveries.

## 🚀 Features

### Customer
- User registration and login
- Browse restaurants and food menus
- Search and filter restaurants
- Place and track orders
- Order history and cancellation
- Submit reviews and return requests
- Manage profile

### Restaurant Owner
- Manage restaurant details
- Add, edit and manage menu items
- Manage incoming orders
- Update order statuses
- Handle return requests

### Delivery Partner
- View assigned deliveries
- Update delivery status
- Manage delivery progress

## 🛠️ Technology Stack

**Frontend:** React.js, CSS, Axios

**Backend:** Python, FastAPI, SQLAlchemy, Pydantic, JWT

**Database:** Microsoft SQL Server

**Tools:** Visual Studio, VS Code, Docker, Git

## 🏗️ Project Structure

- `frontend/` – React application
- `backend/` – FastAPI application
- `database/` – Database scripts (if included)

## ▶️ Running the Project

Frontend:
```bash
cd frontend
npm install
npm run dev
```

Backend:
```bash
cd backend
pip install -r requirements.txt
python -m uvicorn main:app --reload
```
